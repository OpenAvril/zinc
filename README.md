  (4)C **Core_Injection**,

  (5)D **concurrentTask(s)_1**,
  
  (6)D **concurrentTask(s)_2**,

// SIMULATION I and O.

  (9)E **SIM_IN** ***(concurrentTask(s)_3)***,
  
  (10)E **SIM_OUT** ***(concurrentTask(s)_4)***.
